Jarvis, a personal AI memory layer

A server I designed and built that every Claude chat, phone session and voice conversation connects to, so my assistant has the same context about my life everywhere. It runs on Cloudflare Workers and Postgres and is still in progress.

The problem

I use AI assistants all day: in chat, on my phone, by voice. Each one knows only what I've told it in that conversation. My classes, job search, side projects, gym and plans live in my head and get re-explained over and over. The more I used AI, the more time went into catching it up.

How it works

Jarvis is a single server that every assistant connects to through the Model Context Protocol (MCP), the standard way AI apps plug into outside tools. Whatever surface I'm on, the assistant reads from and writes to the same memory.

What it does

  • Captures as I talk. When I mention a task, a workout, a meal, a plan or a new lead, the assistant saves it right away. I don't have to say where it goes.
  • Learns new areas on its own. When something new keeps coming up, like a new class or a new project, Jarvis gives it its own area with a short playbook for how to handle it.
  • Knows what matters and what's going stale. Each area has an importance and a decay rate, so things I care about stay near the top and things I've stopped touching fade instead of cluttering every answer.
  • Briefs me every morning. A short rundown of what's on my plate before the day starts.

Built to be trusted with my life

A memory of everything is only useful if it's safe, so the security came first, not last.

  • Owner-only Google OAuth. The server only accepts my Google account. Nobody else can connect, even with the URL.
  • Least-privilege database access. The server's database role can do exactly what the tools need and nothing more.
  • Every action logged. Every action is recorded, so I can see exactly what an assistant did and when.
